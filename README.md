# HAKI Version Control

HAKI is a web-based version control system developed as a college minor project.

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- React Router
- Vite

### Backend
- Node.js
- Express.js
- REST API

### Data Storage
- JSON
- Node.js File System
